# Blinky-Thunder
This project is fairly simple but interesting to do. It involves LEDs (which blink) attached to a PCB shaped like a thunderclap. It has two main microcontrollers: the NE555P and CD4017, as well as resistors for the LEDs and two capacitors.
I decided to do this project because I realized that it wasn't very complicated to do and it would teach me new things, such as designs and slightly more complicated logic of schemes, as well as routing with an irregular shape.
